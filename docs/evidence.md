# 근거 문서 / Evidence

> 이 문서는 백로그([backlog.md](backlog.md))의 방향 결정과 안내 우선 재정의
> ([agent-copilot.md](agent-copilot.md))의 **근거를 한곳에 모아** 향후 결정이 같은
> 지반 위에서 이뤄지게 한다.
>
> **출처 신뢰도 표기.** 이 근거의 상당수는 자동 문헌 조사로 수집됐고, 당시 다수 검색
> 엔진이 차단되어 초록(abstract) 수준까지만 확인된 항목이 있다. 각 항목에 **[확신도]**
> 를 표기한다: **[확정]** = 1차 출처로 직접 확인, **[초록]** = 초록/요약까지 확인, 본문
> 수치는 재확인 필요, **[정황]** = 시장/맥락 정보로 추가 검증 권장. 수치를 인용해 대외
> 발표할 때는 **[초록]·[정황] 항목을 1차 출처로 재확인**할 것.

## 1. 이 사용자군은 AI 오류를 절반만 잡아낸다 (안내 우선 재정의의 핵심)

- **주장:** 시각장애(BLV) 사용자는 AI가 생성한 이미지 설명의 오류를 약 50% 수준으로만
  탐지한다. 즉 "AI가 행동하고 사용자가 감독·확인한다"는 모델은 감독 채널이 신뢰 불가.
- **출처:** Hong, Kacorri 등, *Blind users' verification/trust of AI-generated image
  descriptions*, **ASSETS 2024** 계열 연구. **[초록]**
- **함의:** 자율 대행(초안 자비스)은 이 사용자군에서 안전 마진이 음수 → **안내 우선 +
  사용자 개시·되돌림 가능 자동화**로 재정의. 자율성 확대는 오류 탐지율 실험
  ([user-testing.md](user-testing.md))으로 실증한 뒤에만.
- **재확인 TODO:** 정확한 탐지율 수치·과제 설정·표본을 1차 논문에서 확인.

## 2. 차트 캡션은 값 오류가 지배적이다 (반날조 가드레일의 근거)

- **주장:** 자동 생성 차트 캡션의 약 **81%가 사실 오류**를 포함하며, 그중 **수치(값)
  오류가 1위**. 저해상도·열화 프레임(인강 캡처 등)에서 더 나빠진다.
- **출처:** Huang 등, 차트 캡션 사실성 분석, **ACL Findings 2024** 계열 **[초록]**;
  열화 조건 악화는 Shin 등(2025) 계열 **[초록]**.
- **함의:** 차트/수식 프로파일에 **화면에 인쇄된 값만 발화, 보간·추정 금지** 하드 규칙
  (Epic A2, 이미 반영). 복습 노트는 사람 검토 전 학습 사용 금지 고지(Epic B1, 반영).
- **재확인 TODO:** 81%·값오류 1위의 정확한 데이터셋·측정 정의 확인.

## 3. 추측성 설명을 거부하는 강한 선호

- **주장:** BLV 사용자의 다수(약 **63%**)가 "짐작/추측 없이 화면에 실제 있는 것만"
  설명하기를 선호. 근거 없는 해석은 신뢰를 떨어뜨린다.
- **출처:** BLV 설명 선호 조사 계열 **[초록]**.
- **함의:** 강의 프로파일에서 "강사가 가리키는 대상을 짐작해 설명" 지시 삭제(Epic A3,
  반영). 안내 텍스트도 화면에 보이는 요소만 지목.
- **재확인 TODO:** 63% 수치의 조사 표본·문항 확인.

## 4. 수식은 이미 성숙하게 해결됐다 (공급자 포지션)

- **주장:** 수식 접근성은 **MathCAT**이 **NVDA 2026.1 본체에 내장**되며 성숙 단계.
  산문(prose) 낭독은 이 스택 대비 열등하고 편집·탐색이 불가.
- **출처:** NVDA 릴리스/ MathCAT 프로젝트 문서 **[정황]**.
- **함의:** 산문 낭독으로 **경쟁하지 말고**, MathML을 산출해 MathCAT/Access8Math에
  **위임하는 공급자**가 되는 것이 유일한 방어 위치(백로그 E1, 보류 — 실기기 필요).
  당장은 수식 프로파일에 반날조 규칙만 강화(A2, 반영).
- **재확인 TODO:** NVDA 2026.1 내장 여부·범위를 릴리스 노트로 확정.

## 5. 게임 실시간 비전 해설은 근거가 반박한다

- **주장:** VLM **전용** 모드의 게임 해설은 플레이 성공률을 유의하게 높이지 못한다.
  실효적 게임 접근성은 구조화된 접근성 데이터로 해결되는 경향.
- **출처:** **GamerAstra** 등 게임 접근성 연구 **[초록]**.
- **함의:** 게임을 flagship에서 강등(README·roadmap 반영), 프로파일은 유지하되 실시간
  비전 해설 확대는 하지 않음.
- **재확인 TODO:** 실험 설계·성공률 지표 확인.

## 6. 한국어는 비어 있는 moat, 학습엔 실수요가 있다

- **언어 moat:** NVDA 애드온 스토어 **503개 중 한국어(`ko`) 번역 0개**. **[정황]**
- **학습 실수요:** 시각장애인 **230명** 표본에서 학업 도표를 **AI로 읽는 비율 7.5%**,
  **50%는 여전히 사람에게 물어봄** — 충족되지 않은 수요. **[초록]**
- **유통 구조:** 국내 보조공학 유통이 **센스리더 보조금 채널** 중심이라 무료 애드온이
  배제되는 경향 → **웹 클라이언트 + MIT 코어**가 애드온만큼(또는 그 이상) 가치 있는 자산.
  **[정황]**
- **함의:** 1차 웨지를 **한국어 학습**으로 확정(README·roadmap M4 반영).
- **재확인 TODO:** 503/0 카운트 시점, 230명 조사의 출처·연도 확정.

## 7. 검증에서 반증되어 **하지 않기로** 한 것

  변경하지 않는다. (`core/bitgil_core/providers/anthropic_provider.py`)
