빛길 (Bitgil)

화면을 공유하면 조용히 지켜보다가, 화면이 크게 바뀌거나 여러분이 물어볼 때 알려 줍니다. OS 구분 없이 — 화면은 그냥 화면입니다.

시험지 PDF로 대화하기 → (지문·선택지는 원문 그대로 읽고, 도표만 모델이 설명합니다)

준비됨. “화면 공유 시작”을 누르세요.

무엇을 할 수 있나요?
  • 지금 화면 설명 (Alt+D) — 언제든 지금 보이는 화면을 설명받습니다(변화가 없어도).
  • 중요한 변화는 자동으로 알림 — 켜 두면 화면이 크게 바뀔 때만 스스로 말합니다. 끄면 부를 때만 말합니다.
  • 자동 알림 민감도 — 얼마나 큰 변화부터 자동으로 말할지 조절합니다.
  • Esc — 낭독을 멈춥니다.

이 웹 모드는 화면을 읽고 설명합니다. 버튼을 대신 눌러 주는 조작(자동화)은 아직 이 경로에 없습니다 — 화면 조작은 OS 연동이 필요한 별도 기능입니다.
